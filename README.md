# Computational Theory: SHA-256

Work for the Computational Theory assessment. It goes through the SHA-256 hash
algorithm from [FIPS 180-4](https://nvlpubs.nist.gov/nistpubs/FIPS/NIST.FIPS.180-4.pdf)
in Python. Everything is in `problems.ipynb`, with one section per problem.

## Setup

```bash
git clone https://github.com/Bartek-Pawlik/ComputationalTheory.git
cd ComputationalTheory
pip install -r requirements.txt
```

## Running

```bash
jupyter notebook problems.ipynb
```

Then choose **Kernel → Restart Kernel and Run All Cells**. You can also open
the notebook in VS Code with the Jupyter extension.
